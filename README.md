# MingChaoBQ-Yunzai

鸣潮表情包云崽（Yunzai）插件，移植自 GsCore 插件 `Xbaiyz12/MingChaoBQ`。

支持随机表情、按画师/角色/表情名检索、缩略图列表、连发合并转发、图片上传、呜哇小站搜索与拉取、戳一戳随机表情、戳一戳统计、群白名单与黑名单、屏蔽词，以及每日索引自动更新。

## 安装

1. 将整个 `MingChaoBQ-Yunzai` 目录放入云崽根目录的 `plugins/` 下。
2. 确认云崽已经安装依赖（本插件只依赖 `yaml`，云崽本身已带）。
3. 重启云崽。
4. 发送 `bq帮助` 查看帮助图。

首次执行 `bq更新索引` 时会自动下载约 143MB 的内置表情包，安装到 `data/MingChaoBQ/`。下载地址可在配置中替换为国内镜像。

## 命令

### 普通用户

| 命令 | 说明 |
| --- | --- |
| `bq随机表情` | 从全部表情中随机发送一张 |
| `bq随机表情 画师名` | 从指定画师的作品中随机发送 |
| `bq随机表情 角色名` | 从指定角色中随机发送，本地没有时向小站取图 |
| `bq随机表情 表情名` | 按表情名随机发送 |
| `bq本地表情 [关键词]` | 只从本地图库取图 |
| `bq列表` | 画师与角色总览 |
| `bqXX列表` | 缩略图列表，回复 `表情N` 发送对应图片 |
| `bq三连 [关键词]` | 连续发送 3 张 |
| `bq连发 [数量] [关键词]` | 连续发送 1 到 5 张 |
| `bq帮助` | 帮助图 |
| `bq表情统计` | 角色表情发送排行 |
| `bq戳一戳统计` | 被戳次数与用户排行 |
| `bq设置戳一戳角色 角色名` | 设置本群戳一戳固定角色 |
| `bq设置戳一戳角色 随机` | 恢复本群戳一戳随机表情 |

### 主人命令

| 命令 | 说明 |
| --- | --- |
| `bq添加表情 [画师] [角色] [表情名]` | 发图上传，支持 `画师:名字` 强制新建目录 |
| `bq更新索引` | 重新扫描图库，必要时下载内置包 |
| `bq下载表情包` | 强制下载并补齐内置表情包 |
| `bq网站搜索 关键词` | 搜索呜哇小站角色与表情包 |
| `bq拉取角色 角色名 [张数]` | 从小站按角色拉取 |
| `bq拉取画师 画师名 [角色] [张数]` | 从小站按画师拉取 |
| `bq拉取表情包 包名或slug [张数]` | 从小站按表情包拉取 |
| `bq画师榜` / `bq画师列表` | 小站画师榜，并标注本地已有数量 |
| `bq屏蔽表情 关键词` | 拉取和随机时跳过命中关键词的网站表情 |
| `bq解除屏蔽 关键词` | 移除屏蔽词 |
| `bq查看屏蔽` | 查看屏蔽列表 |
| `bq开启戳一戳` / `bq关闭戳一戳` | 开关戳一戳随机表情 |
| `bq开启白名单` / `bq关闭白名单` | 开关群白名单 |
| `bq添加白名单 群号` / `bq移除白名单 群号` / `bq查看白名单` | 白名单管理 |
| `bq添加黑名单 群号` / `bq移除黑名单 群号` / `bq查看黑名单` | 黑名单管理 |

命令前缀 `#`、`bq`、`鸣潮` 都可省略或组合使用，例如 `随机表情`、`#鸣潮列表`。

## 配置

配置文件：`config/config.yaml`。修改后重启云崽生效。

常用项：

- `mcbq_enable`：总开关。
- `mcbq_api_enable`：优先从呜哇小站随机接口取图。
- `mcbq_api_save_local`：API 取到的图保存到 `data/MingChaoBQ/API/角色名/`。
- `mcbq_builtin_auto_fetch`：首次更新索引时自动下载内置包。
- `mcbq_builtin_pack_url`：内置包地址，可换成镜像直链。
- `mcbq_site_enable`：启用呜哇小站接口。
- `mcbq_site_fetch_max`：单次拉取上限，0 表示不限制。
- `mcbq_block_list`：屏蔽词列表。
- `mcbq_poke_enable`：戳一戳开关。
- `mcbq_poke_group_roles`：群号与固定角色，格式 `群号:角色名`。
- `mcbq_upload_pm`：添加表情所需权限，0 主人、2 群主、3 管理员、6 所有人。
- `mcbq_index_auto_update`：每日索引自动更新。
- `mcbq_index_update_hour` / `mcbq_index_update_minute`：自动更新时间。

## 数据目录

```
data/MingChaoBQ/
  画师名/
    角色名/
      表情名.gif
  API/
    角色名/
      id_md5.gif
  index.json
  statistics.json
  .builtin_pack.json
  cache/
```

索引结构与原版一致：`{ 画师: { 角色: { 子分类: [ { file, emotion, source? } ] } } }`。

## 与 GsCore 版的差异

- 命令、权限、配置键名、数据目录与索引结构保持兼容。
- 列表图、排行图、帮助图改用 Puppeteer 渲染 HTML，不再依赖 Pillow。
- 事件等待改为监听云崽 `Bot` 的 `message.group` / `message.private` 事件。
- 定时任务改为每分钟检查一次的 `setInterval`。
- 配置从 GsCore 控制台配置迁移到 `config/config.yaml`。
